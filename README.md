# Мои проекты

Программы для macOS и небольшие сайты.

## Программы для macOS

| Проект | Для чего нужен |
|---|---|
| [Карта диска](https://github.com/turbopash/DiskMap) | Показывает, чем занят диск, находит крупные файлы и дубликаты. Аналог SequoiaView |
| [Phone Commander](https://github.com/turbopash/PhoneCommander) | Двухпанельный файловый менеджер с доступом к iPhone по кабелю |
| [Поиск фото по образцу](https://github.com/turbopash/PhotoFinder) | Находит в папках копии и похожие снимки, всё работает на самом Mac |
| [PhotoShuffle](https://github.com/turbopash/PhotoShuffle) | Случайный показ фото и видео из папки, распознавание людей и предметов. [Скачать](https://github.com/turbopash/PhotoShuffle/releases/latest) |

## Сайты

| Сайт | Для чего нужен | Код |

| [Лёва читает](https://turbopash.github.io/leva-chitaet/) | Детский тренажёр чтения: буквы, слоги, слова | [leva-chitaet](https://github.com/turbopash/leva-chitaet) |
| [Тренажёр ОГЭ-9](https://turbopash.github.io/oge/) | Подготовка к ОГЭ | [oge](https://github.com/turbopash/oge) |
| [Reels Hub](https://turbopash.github.io/reels-hub/) | Личная лента трендовых роликов и музыки с возможностью скачать | [reels-hub](https://github.com/turbopash/reels-hub) |
