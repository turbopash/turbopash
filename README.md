# Мои проекты

Программы для macOS и небольшие сайты.

## Программы для macOS

| Проект | Для чего нужен |
|---|---|
| [Карта диска](https://github.com/turbopash/DiskMap) | Показывает, чем занят диск, находит крупные файлы и дубликаты. Аналог SequoiaView. [Скачать](https://github.com/turbopash/DiskMap/releases/latest/download/DiskMap.zip) |
| [Phone Commander](https://github.com/turbopash/PhoneCommander) | Двухпанельный файловый менеджер с доступом к iPhone по кабелю. [Скачать](https://github.com/turbopash/PhoneCommander/releases/latest/download/PhoneCommander.zip) |
| [Поиск фото по образцу](https://github.com/turbopash/PhotoFinder) | Находит в папках копии и похожие снимки, всё работает на самом Mac. [Скачать](https://github.com/turbopash/PhotoFinder/releases/latest/download/PhotoFinder.zip) |
| [PhotoShuffle](https://github.com/turbopash/PhotoShuffle) | Случайный показ фото и видео из папки, распознавание людей и предметов. [Скачать](https://github.com/turbopash/PhotoShuffle/releases/latest) |

Программы рассчитаны на Mac с Apple Silicon. Как установить, написано в README каждого проекта.
